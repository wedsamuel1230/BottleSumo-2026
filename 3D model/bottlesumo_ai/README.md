# bottlesumo_ai

New assembly workspace definition for the BottleSumo chassis. The authoritative
feature order and parameters are documented in
[`docs/bottlesumo_ai-assembly-timeline.md`](../../docs/bottlesumo_ai-assembly-timeline.md).

This folder is intentionally separate from `3D model/v1`; the v1 Fusion assets
remain reference geometry and are not overwritten.

## Referenced components

- `Motor 24GP.f3d`
- `MOTOR STAND 24GP.f3d`
- `High Grip Wheel.f3d`
- `VL53L0X_TOF.f3d`
- `QRE1113 sensor module.f3d`
- `E326S-Battery.f3d`

The Fusion 360 timeline itself must be created in a Fusion-compatible CAD
session using the documented feature order. Exact E326S and motor dimensions
remain fit-verification inputs.
