# BottleSumo 2026 策略筆記

來源賽規：[CTEA 2026 Rev.1](https://ctea.org.hk/media/attachments/2026/08/15/2026_rules_06.pdf)。
本檔只記錄由賽規推導出的戰術決定，以及 Arduino 韌體的對應實作。

## 規則約束

| 規則 | 出處 | 對策略的影響 |
| --- | --- | --- |
| 只有單一機械人以**正面持續接觸**水樽直到它離開台板，才算「故意」 | §4.1 | 接觸後必須直推，不可在接觸中旋轉 |
| 正面接觸過、之後在旋轉中掉出，判為「非故意」 | §4.2 | 60° 甩樽動作不可用於取勝 |
| 側面或背面接觸令水樽掉出，判為「非故意」 | §4.2 | 不可用車身側面掃樽 |
| 水樽推出後，機械人須留在台上至少 3 秒 | §3.C.V | 推完要停止／後退，不可衝落台 |
| 30 秒雙方無接觸、無進展、無動作 → 平手 | §3.C.V.c | 要主動找對手，不可只繞圈 |
| 高級組用 Senior A / B 未知排列，水樽在接縫線上 | §3.1 | 開局要朝接縫線走，不能假設固定起點 |
| 每局 2 分鐘、三局兩勝 | §3.B | 開局路徑要短，5–8 秒內要取得水樽或對手 |

## 目前韌體的做法

1. **地圖選擇**：SW2 開 Senior A、SW3 開 Senior B；Web／Console 亦可開單板。
   `commitPlan()` 為每個地圖提供固定腿序（直行 → 轉向 → 直行 → 微弧 → 直行）。
2. **固定開局**：`Opening` 由 `openingStartMs` 計時，`openingCommitMs` 上限 6 秒；
   任何確認邊緣立即轉 `Escape`，中心 ToF ≤ `openingAbortMm`（300 mm）提早接手。
3. **取得水樽**：中心 ToF 兩次連續有效才確認目標；進入 `Approach`，近距離用
   `approachNear`，遠距離用 `approachFar`。
4. **接觸後直推**：`Carry` 保持雙輪同速（`carryPwm`），只用 `pushSteerMax`
   修正航向，讓正面持續貼住水樽，符合 §4.1。
5. **邊緣處理**：QRE 去抖 25 ms；`Escape` 後退 → `Hold` 3.5 秒，覆蓋 §3.C.V 的
   3 秒留台要求。
6. **找對手**：ToF 會把對手與水樽都當成前方目標；`Search` 的掃描會持續轉向，
   30 秒內應能接觸對手，避免 §3.C.V.c 的無接觸平手。

## 為何不做「接觸中轉 60°」

賽規 §4.2 明文把「正面接觸過，然後在旋轉時令水樽掉落」列為非故意。360° 或 60°
的甩樽只有在**未接觸**時才有意義（重新對位、繞過對手），不能在推樽途中使用。

若要重新對位，安全順序是：失去中心目標 → `Search` 轉向 → 重新正面接近；
`Carry` 不會主動脫離接觸去轉向。

## 待實測

- `carryPwm` 能否在 2 L 水樽（約 1 L 水）上維持不打滑；打滑時提高 `carryPwm`，
  不要靠轉向。
- QRE 在實際白色／淺灰台板與膠紙上的分離度；每通道 ≥300 counts。
- 邊緣後退距離（`escapePwm`）與 3.5 秒 Hold 是否真的留在台上。
- 開局腿序在 Senior A / B 實際起點的量測；現值為估計，需在場地重測。
